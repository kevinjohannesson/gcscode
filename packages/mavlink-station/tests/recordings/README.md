# Recordings

Recorded radio sessions that `tests/replay.rs` replays through the station's radio side, each checked at every 20 ms tick against the recording folded to that instant. Every `.jsonl` file here is picked up. The format is the [virtual radio spec](../../../../docs/specs/2026-11-24-virtual-radio.md)'s; `radio-probe --record` writes one ([its README](../../../../tools/radio-probe/README.md#recording-and-replaying)).

Each file is cut to one purpose and kept under about 1 MB (some 30 s of a moving stick). `adv-sweep.jsonl` is the exception at 3.6 MB: it moves every input in turn over 140 s, so a cut would drop inputs.

| File                               | What happened while recording                                                                                                                                                                                                                                         | Radio                                        |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `synthetic-sweep-and-replug.jsonl` | Not a radio: written by hand for the first tests. Throttle ramps up and roll sweeps for 1 s, SA's top button pulses, control goes on, then an unplug and a replug with throttle held at 12000 and control on.                                                         | gcscode-adv's shape: 8 axes, 28 buttons      |
| `adv-sweep.jsonl`                  | The owner's TX16S, idle for the first 17 s while recording started (no lines), then each stick through its full range one after another (throttle, yaw, pitch, roll, then the four other axes), then every switch through its positions (buttons 0 to 21). No unplug. | TX16S MK3 on gcscode-adv, USB Joystick (HID) |
| `adv-replug-deflected.jsonl`       | The owner's TX16S, held still, unplugged at 8.2 s, plugged back in at 25.9 s with the throttle held at 17567, then pushed to about 18500 and held there, where it jitters by one step.                                                                                | TX16S MK3 on gcscode-adv, USB Joystick (HID) |
