# map-gl-svelte

A Svelte 5 port of `@vis.gl/react-maplibre`, the MapLibre bindings of react-map-gl. The public API follows upstream's; the internals use Svelte's own fine-grained reactivity. This package is a standalone artifact housed in the gcscode repo, private and consumed from source.

_Work in progress: usage, the Svelte-translations table and the upstream pin are written up once the port is complete._

This package is a port of [`@vis.gl/react-maplibre`](https://github.com/visgl/react-map-gl) (react-map-gl v8.1.3, MIT, Copyright Vis.gl contributors). See `LICENSE`.
